# Baby Care App

An AI-powered mobile application that helps parents understand their baby's emotions and needs through real-time camera analysis.

## Features

- **Real-time Emotion Detection**: Identifies baby's emotional state (happy, crying, neutral, tired, laughing)
- **Smart Suggestions**: Provides contextual care recommendations based on detected emotions
- **Privacy First**: All processing happens on-device - no images are uploaded to servers
- **Mood History**: Tracks baby's emotional patterns over time
- **Night Mode**: Red-tint dark mode for nighttime use without disrupting night vision

## Getting Started

### Prerequisites

- Flutter SDK 3.0+
- iOS 12+ or Android 8+
- Physical device (camera required)

### Installation

1. Clone the repository
2. Run `flutter pub get`
3. Connect a physical device
4. Run `flutter run`

## Privacy

This app processes all data locally on your device. No images, audio, or personal information is ever transmitted to external servers.
